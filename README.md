# QR Scanner

QR Scanner — QR Code Scanner/Generator PWA.

## Features

- Real-time QR code scanning via camera
- QR code generation from text and URLs
- Scan history with timestamps
- Copy decoded content to clipboard
- PWA for offline-capable scanning

## Tech Stack

React · Vite · Tailwind CSS · Camera API · PWA

## Quick Start

```bash
git clone https://github.com/D-VKITZ/qr-scanner.git
cd qr-scanner
npm install
npm run dev
```
